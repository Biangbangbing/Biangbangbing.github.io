python使用Matplotlib论文绘图

官方手册：https://matplotlib.org/stable/api/axes_api.html

一、基础概念​

1. 引用库以及包​

绘图使用到malpoltlib包，使用之前安装包，并在对应.py文件中导入库文件

# 在对应的环境中安装malplotlib包（
conda install malplotlib

#导入matplotlib的pyplot模块
import matplotlib.pyplot as plt

2. 基础知识​

matplotlib模块下有若干个类，pyplot，axes，axis，figure，legend等等，plot主要用来绘制图，在屏幕生生成图像，是图像GUI管理器。因此首先引入pyplot模块。

  1. 绘图有画板figure，首先生成画板可以控制生成画的大小。

  2. 绘图有axes相当于一个子plot（sub-plot），相当于画纸

  3. 绘图坐标轴axis，坐标轴刻度tick，坐标轴范围lim，标签label，标题title，图例legend，注释annotate，网格grid。这些元素无论在任何类型的图中都有可能需要设置。

    1. axis

    2. tick：刻度线，需要赋值数组/列表绘制刻度；可以在刻度上显示实际想要显示的数字，用label赋值。

    3. lim：坐标轴取值范围，赋值最小值，最大值即可。

    4. label：坐标轴名称。可以控制坐标轴名称文本框和坐标轴的距离。可以控制对应名称的字体。

    5. title：图的名称。

    6. legend：见不同图的设置方法。

    7. annotate：注释。

    8. grid：图内表格。

      plt.yticks(np.arange(0, 1.1, 0.2), fontsize=16)

      plt.xlim(0, 0.0103) # 参数为最小值，最大值

      plt.grid(alpha=0.4, axis='y', zorder = 0) # alpha控制格线的透明度;axis控制格线，可取x,y,all;

二、常用图形​

1. 散点图​

x=[1,2,3,4]
y=[1,4,9,16]

for index in range(4):
    plt.scatter(x[index],y[index],color = colors[index],marker = makers[index],label = legend[index],s = 150)
    plt.legend(prop={'size': 15, 'weight': 'bold', 'family': 'Calibri'}, loc='best')

绘制一个点，需要x坐标和y坐标，绘制点的颜色color，点的形状marker（默认为'o')；赋值label之后，绘制图例直接直接填入参数prop，loc就好。

每绘制一个点的图例都要调用一次plt.legend。

柱形图有多种分类，分别进行讲解。绘制柱形图需要x，y，一组xy列表，对应一组柱子（多少个xy，多少个柱子）。

  1. 柱状图分类：

    1. 多个类别柱状图

      1. 需要使用plt.bar()绘制柱形。

      2. 需要控制柱形的位置，第一个参数为每组柱子的中间位置的x轴位置，每组柱形不能重叠，x轴的位置需要错开。

      3. 需要设置柱子的宽度，width参数。

    2. 堆积柱状图

      1. 同样使用plt.bar()绘制柱形。

      2. 堆积柱状图的多组柱子x轴相同，只是在y轴的同一个x轴位置累加，因此需要控制不同组柱子的bottom值。让第x组的柱子的bottom值是x-1组柱子的顶端y值。

  2. 绘制柱形图特有参数

    1. 前文的柱子宽度width。
    2. 柱子内部图案填充：hatch。
      1. 取值参数：{'/', '\', '|', '-', '+', 'x', 'o', 'O', '.', '*'}
      2. 个数可以添加，个数越多，密度越大，eg：'///'
      3. 可以相互组合，eg：'/+'

# 可设置格式为
Tick formatting
---------------

Tick formatting is controlled by classes derived from Formatter. The formatter
operates on a single tick value and returns a string to the axis.

:class:`NullFormatter`
    No labels on the ticks.

:class:`IndexFormatter`
    Set the strings from a list of labels.

:class:`FixedFormatter`
    Set the strings manually for the labels.

:class:`FuncFormatter`
    User defined function sets the labels.

:class:`StrMethodFormatter`
    Use string `format` method.

:class:`FormatStrFormatter`
    Use an old-style sprintf format string.

:class:`ScalarFormatter`
    Default formatter for scalars: autopick the format string.

:class:`LogFormatter`
    Formatter for log axes.

:class:`LogFormatterExponent`
    Format values for log axis using ``exponent = log_base(value)``.

:class:`LogFormatterMathtext`
    Format values for log axis using ``exponent = log_base(value)``
    using Math text.

:class:`LogFormatterSciNotation`
    Format values for log axis using scientific notation.

:class:`LogitFormatter`
    Probability formatter.

:class:`EngFormatter`
    Format labels in engineering notation

:class:`PercentFormatter`
    Format labels as a percentage
