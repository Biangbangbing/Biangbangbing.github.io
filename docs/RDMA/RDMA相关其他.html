13.其他相关

1.PFC相关​

1. 阈值触发的位置​

  • 输入端口队列监控：

    PFC的核心机制是通过监控入端口的缓冲区（Buffer）队列深度来判断是否触发流量控制。当入端口缓冲区中某个优先级的队列长度超过预设的XOFF阈值时，交换机会向发送端（上游设备）发送PFC暂停帧（PFC Pause Frame），要求暂停该优先级的数据传输

  • XOFF：队列达到此阈值时触发暂停。

  • XON：队列低于此阈值时发送恢复帧，恢复传输3。

  • 输出端口无关性： 出端口的队列状态不会直接触发PFC。PFC的阈值判断和流量控制完全基于入端口的缓冲状态，目的是防止入端口因拥塞导致数据丢包89。

2. PFC的工作流程​

  1. 数据接收： 数据从发送方的出端口进入接收方的入端口，根据优先级分类到对应的入端口队列中3。
  2. 阈值判断： 入端口持续监控各优先级队列的深度。若队列长度超过XOFF，触发PFC暂停帧；若低于XON，发送恢复帧38。
  3. 暂停帧发送： 暂停帧会直接传递给上游设备的出端口，要求其暂停特定优先级的数据发送29。

3. 关键设计原因​

  • 防止入端口拥塞： 入端口是数据进入交换机的第一站，若其缓冲区溢出会导致数据丢失。PFC通过入端口监控提前干预，避免拥塞扩散23。
  • 优先级独立性： PFC允许对不同优先级的流量独立控制（例如RoCE流量和普通TCP/IP流量），确保高优先级业务不受低优先级流量影响89。

4. 配置示例​

在交换机中，PFC的阈值（XON/XOFF）通常通过以下配置实现：

# Mellanox交换机示例（基于RoCE场景）
interface ethernet 1/1-1/32 
  ingress-buffer pool iPool0 type lossy reserved 20K shared alpha 8 
  dcb priority-flow-control mode on force 
  dcb priority-flow-control priority 4 enable

此配置针对入端口的缓冲区分配和优先级队列阈值进行设定9。

总结​

  • 阈值判断位置：交换机的输入端口（入端口）。
  • 触发条件：入端口的队列深度超过XOFF或低于XON。
  • 目的：通过入端口主动反压上游设备，实现无损传输和优先级保障238。

2.PFC watch dog工作原理​

  • Watchdog的整合：若PFC机制失效（如暂停帧未正确处理或拥塞持续超时），Watchdog可能通过以下方式工作：
    1. 定时检测：监控PFC相关队列的状态，例如检测队列深度是否超过阈值或暂停帧的响应时间。
    2. 超时触发恢复：如果PFC未能在预定时间内解决拥塞，Watchdog会触发网络设备的端口复位、路径切换或告警通知，避免系统陷入不可恢复的拥塞状态8。

3.如何减少端侧CQE​

减少CQE，降低CPU开销，提高系统吞吐量。

1.请求聚合​

  • 批量提交请求【】

    • 将多个WR（Work Request）合并为一个WR链

    • 使用IBV_SEND_INLINE标志发送小消息

      struct ibv_sge sge_list[BATCH_SIZE];
      struct ibv_send_wr wr_list[BATCH_SIZE];
      // 准备批量WR
      for (int i = 0; i < BATCH_SIZE; i++) {
          wr_list[i].next = (i == BATCH_SIZE-1) ? NULL : &wr_list[i+1];
          wr_list[i].sg_list = &sge_list[i];
          wr_list[i].num_sge = 1;
          wr_list[i].opcode = IBV_WR_SEND;
      }
      ibv_post_send(qp, &wr_list[0], &bad_wr);  // 单次提交多个WR

  • 使用SEND/WRITE_WITH_IMM【】

    • 立即数操作将数据和完成通知合二为一
    • 避免单独的完成通知

2.完成事件优化​

  • 选择性事件生成【控制只有某些事件完成后进行通知】

    struct ibv_qp_init_attr qp_init_attr = {
        .sq_sig_all = 0,  // 不自动为每个WR生成CQE
        // ...其他参数
    };
    // 只在关键WR设置IBV_SEND_SOLICITED标志

  • CQE压缩（需要硬件支持）【】启用网卡的CQE压缩功能

    # 查询设备能力
    ibv_devinfo | grep cqe_compression
