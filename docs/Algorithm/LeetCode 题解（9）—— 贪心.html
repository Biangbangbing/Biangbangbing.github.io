1.455.分发饼干

解题思路​

想要把饼干分给尽可能多的人，就要避免浪费：就是每次把没有分的最小的饼干分给第一个刚好可以接受他的人。

解题流程​

方法1

将人的胃口g和饼干大小s 分别从小到大排序。

然后for开始遍历胃口g：同时额外设置索引j查看当前饼干：

如果当前胃口 <= 当前饼干，饼干索引 j++，计数count++；

如果当前胃口 > 当前饼干，饼干索引 j++，但是胃口索引 i 不变，所以要用while循环给 j++，同时需要注意不要超出饼干索引的最大范围；

最后返回count；

int findContentChildren(vector<int>& g, vector<int>& s) {
        int g_len = g.size();
        int s_len = s.size();
        sort(g.begin(), g.end());
        sort(s.begin(), s.end());
        int j = 0;
        int count = 0;
        for (int i = 0; i < g_len && j < s_len; i++) {
            while (j < s_len && s[j] < g[i]) {
                j++;
            }
            if (j >= s_len)
                break;
            count++;
            j++;
        }
        return count;
    }

方法2

发现无论每次胃口符不符合这个饼干，饼干的个数都要++，但是胃口符合，人的索引才往前走。

因此不如直接以饼干索引做for循环，

当人的胃口可以接受这个饼干的时候，人的索引++，并且计数；

否则不做任何操作，进行下一次for循环【找下一块大饼干看看】。

方法3

用小饼干满足小胃口，当然也能用大饼干优先满足最大胃口的人。

分析思路同上： 饼干胃口从大到小排序，

for循环遍历人，

当前饼干满足当前这个人的胃口，饼干索引++；

否则不做任何操作，进行下一次for循环【找下一个胃口小的看看】。

2.376.摆动序列

解题思路​

注意题目要求的摆动子序列。

子序列：每个元素出于原序列，元素相对位置不变，但是不要求必须连续。

子串：每个元素出于原序列，且必须是原序列连续的一段。

因此只需要遍历整个序列，有摆动的时候使记录的长度++，更新符号记录；

没有摆动的时候什么都不用做。

如何记录摆动：当前元素和上一个元素相比的差值的符号，与上一次记录的符号相反就是摆动；或者这一次有符号变化，上一次没有变化【只有刚开始的时候记录变化的符号有可能为0，其他不变化的时候符号记录停留在上一次的符号】。

为了避免开始一直是平缓期，我用while首先确定找到了第一个摆动的位置，然后开始for循环遍历，其实不需要这一步也可以直接for循环【如果这一次等于上一次的值，没有摆动那么会继续下一次循环，不会做任何处理；如果上一次没有摆动，这一次有摆动就会更新摆动符号然后计数。所以是包含了找到第一个摆动序列的操作的】

相较之下while提前处理的：就是代码写的比较复杂，逻辑有点碎，因为是for接着while遍历，所以时间复杂度还是O（n），空间复杂度也一样。

//while提前处理过的
int wiggleMaxLength(vector<int>& nums) {
        int flag = 0;
        int len = nums.size();
        if (len == 1)
            return 1;
        // 子序列：
        int pre = nums[0], count = 1;
        int j = 1;
        while (j < len && nums[j] == nums[j - 1]) {
            j++;
            if (j == len)
                return count;
        }
        if (nums[j] > nums[j - 1])
            flag = 1;
        else
            flag = -1;
        pre = nums[j];
        count = 2;
        for (int i = j + 1; i < len; i++) {
            if (nums[i] > pre) {
                if (flag == -1) {
                    count ++;
                    flag = 1;
                }
                pre = nums[i];
            }
            else if (nums[i] < pre) {
               if (flag == 1) {
                    count ++;
                    flag = -1;
                }
                pre = nums[i];
            }
        }
        return count;

            }
        }

}

3.53.最大子序和

看题意是找到序列的一个连续子序列，使其和最大。

思路：​

用一个长度为输入序列长度的数组a记录以当前元素结尾的子序列最大和。

a数组更新条件：

如果a[i - 1] > 0, a[i] = a[i - 1] + nums[i]；当前的数接到前面的最大长度之后。

如果a[i - 1] <=0, a[i] = nums[i]; 当前数另开一个序列。

a数组排序最大值就是最大和。

int maxSubArray(vector<int>& nums) {
        // vector<int> temp(nums.begin(),nums.end());   不需要另开空间，原数组就可以
        int len = nums.size();
        int maxx = nums[0];
        for (int i = 1; i < len; i++) {
            if (nums[i - 1] > 0)
               nums[i] += nums[i - 1];
            // nums[i] = max(nums[i], nums[i] + nums[i - 1]);
            if (nums[i] > maxx)
                maxx = nums[i];
        }
        return maxx;
    }

4.122. 买卖股票的最佳时机 II

根据题意股票买卖时机：

买：第一次买，每次卖的时候买。

卖：下一次要发生下降的时候卖出去。

start：记录买的时候的价钱。

end：记录卖的时候的价钱。

sum：记录赚的总钱数。

从第二天开始遍历数组：

如果今天的股票价格高于昨天，end更新为今天的价格。

如果今天的股票价格低于昨天，sum += （end - start），并且令start = end = 当前的股票价格，当前的卖出去再买。【如果明天还是继续跌，就相当于今天买，今天又卖了，不赚不赔】

如果当前是最后一天，卖出去 sum += （end - start）。

最终sum就是得到的最多钱。

int maxProfit(vector<int>& prices) {
        int start = prices[0], end = start;
        int len = prices.size();
        int sum = 0;
        for (int i = 1; i < len; i++) {
            if (prices[i] < prices[i - 1]) {
                sum += (end - start);
                start = end = prices[i];
            }  
            else if (prices[i] > prices[i - 1])
                end = prices[i];
            if (i == len -1) 
                sum += (end - start);
        }
        return sum;
    }

这个题目还有一个小巧思来解决：

一次性赚的钱可以拆分为每天都赚的钱：今天买，明天卖，如果赚了就加起来；如果赔了就不管 。

这次不一样的是含有手续费，不可以无限次买卖。我拿到题目思考的时候想的很复杂，就是我要考虑什么时候卖出去：

连续赚钱的时候一定是连续跟不卖，但不连续的时候我这次是卖掉到底再买还是一直到下一次再卖？这就需要对比我卖了再买多挣的钱够不够多一次手续费，够就卖，不够就一直跟。

处理是否连续【只需要一次手续费用】，以及判断是否卖掉的判断逻辑比较复杂，或许还需要设计标记，但是通过分析整理就可以得出下面直接通过数据的补齐获得较为简洁但是抽象的写法。

编辑

int maxProfit(vector<int>& prices, int fee) {
        //需要将手续费先支付，每一次算利润都补上，只有断开才是真正支付
        int len = prices.size();
        int minn = prices[0], sum = 0;
        for (int i = 1; i < len; i++) {
            if (prices[i] > minn + fee) {             //能保证赚钱（之前没买的时候保证的是赚够手续费）;之前如果买了，判断实际上是否还是涨
                sum += (prices[i] - minn - fee);
                minn = prices[i] - fee;               //补偿这一次的手续费，下一次扣
            }
            else if (prices[i] <= minn + fee && prices[i] >= minn)//赚不了钱
                continue;
            else
                minn = prices[i];     //最小值更新为新的，刚刚的手续费的确花了

        }
        return sum;
    }

5.55. 跳跃游戏

首先明确：每个位置头上标的数字是最大长度，可以跳1 —— 这个长度。

要看是否可以到达终点：从头开始跳，企图找一个路径一路到最后，但是一次可以跳好几轮，谁知道跳到哪合适。大致想了一下这不得回溯遍历所有情况，到不了再跳回去。直到找到一个解。

想想有点麻烦，先来看看跳不到是个啥情况：最后一步都跳到了一个死结点，这个结点最连一步都跳不了——头上标的是0。只要路径上不包含这样的死结点就一定可以到最后。

于是可以倒着查看是否存在这样的死结点：

将大问题拆解为小问题：

如果倒数第二个结点可以抵达最后一个结点，那如果从开始可以抵达倒数第二个结点，就可以保证抵达最后一个结点。

如果倒数第二个无法到达判断倒数第三个是否可以到达。

依次类推直到拆解为第一个结点与第二个结点的关系。

bool canJump(vector<int>& nums) {
        int len = nums.size();
        int need = 1, flag = 1;
        if (len == 1)
            return true;
        for (int i = len - 2; i >= 0; i--) {
            if (nums[i] >= need) {
                need = 1;
                flag = 1;
            }
            else {
                need++;
                flag = 0;
            }
        }
        if (flag == 0)
            return false;
        else
            return true;
    }

6.45. 跳跃游戏 II

不光用于检测是否可以到达，而是要找一条最短的路径。

设置数组a记录开始结点到达当前位置的最少步数。

更新a数组：每次当前位置cover到的范围，a更新为当前位置的最小步数+1【如果当前位置+1更小的时候更新】。

int jump(vector<int>& nums) {
        int len = nums.size(), cover = 0;
        vector<int> a(len, len);
        a[0] = 0;
        for (int i = 0; i < len; i++) {
            cover = nums[i];
            for (int j = i + 1; j <= i + cover && j < len; j++) {
                if (a[j] > a[i] + 1)
                    a[j] = a[i] + 1; 
            }
        }
        return a[len - 1];
    }

7.1005. K 次取反后最大化的数组和

将数组从小到大排序，遍历：

如果k没用完，且当前还是负数，反转；

如果k没用完，且当前是0，k = 0；

如果k没用完，且当前是正数，如果当前k有奇数个，如果原来的负数更接近0，就将sum-=上一个数*2；如果现在这个数更接近0，当前数反转，并将k = 0;

如果循环结束之后k仍然>0，说明全是负数，且没有把k用完，所以根据剩余k的奇偶来判断是否需要 - nums[len - 1] * 2。【奇数就需要减，偶数相当于不用管】

int largestSumAfterKNegations(vector<int>& nums, int k) {
        int len = nums.size();
        sort(nums.begin(), nums.end());
        int sum = 0;
        for (int i = 0; i < len; i++) {
            if (k > 0 && nums[i] < 0) {
                nums[i] *= (-1);
                k--;
            }
            else if (k > 0 && nums[i] == 0) {
                k = 0;
            }
            else if (k > 0 && nums[i] > 0) {
                if (k % 2 !=0 ) {
                    if (i > 1 && nums[i - 1] < nums[i])
                        sum -= (nums[i - 1] * 2);
                    else 
                        nums[i] *= (-1);
                }
                k = 0;
            }
            sum +=nums[i];
        }
        if (k > 0 && k % 2!=0) {
            sum -= (nums[len - 1] * 2);
        }
        return sum;
    }

ps：发现如果在排序的时候是按照 绝对值从大到小 排序的会使代码更简洁。

8. 134. 加油站

这道题目要求能够连续加油连续走不会把油箱耗干，这个问题存在于尤其是开始的某些时段——可能加油比较少，耗油比较多会造成油不够的情况，需要我们判断从哪个地方开始油会一直保持有直到再次绕回这个点。因为有的话结果唯一，所以一旦找到就可以结束返回结果。

思路： n：路上节点个数

把圈拆成两条路首位相连，for循环长度2n。

设置油箱内有油sum = 0，准备记录开始站点序号index = 0。

sum += （当前加的油 - 当前消耗的油）【当前节点到下一节点的耗油被记在当前节点上】

如果这个结点使得sum < 0，就让index = i + 1，说明当前节点消耗太多了，前面累计的油都被耗光了：说明从上一次记录到当前的每一个节点一定都不能作为开始节点，所以另index = i + 1。

要注意 index 不可能 >= len,一旦发现等于，就可以直接return -1【表示没找到】。

如果当前的长度，也就是距离上一次记录位置，到目前的结点刚好够一周的长度，那么就代表上一次找到的结点可以返回一周，将这个index return。

int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
        int len = gas.size();
        vector<int> a(len);
        for (int i = 0; i < len; i++) {
            a[i] = gas[i] - cost[i];
        }
        int sum = 0, index = 0;
        for (int i = 0; i < len * 2; i++) {
            sum += a[i % len];
            if (sum < 0) {
                sum = 0;
                index = i + 1;
                if (index == len)
                   return -1;
            }
            if (i - index + 1 == len)
                return index; 
        }
        return -1;
    }

【这个题有个暴力解法：就是尝试每一个节点，走一圈看看有没有解，有解直接return，遍历完都没有就return -1】

9.135. 分发糖果

难题！​

开始我想的是最低的那个给1，然后左右两边分别升1个给1个，但是发现根本无法控制边界，如果升的很高，但是再下降的时候不用依次下，可以直接跳到一个很低的值怎么办；如果打算每次都从波谷往上升，边界如何解决；而且因为连续相等的值处于边界的和平缓的虽然值一样，但是分的糖果数可以不一样比较难解决。

所以这并不是一个好办法。

所以遇到这种可以变量因素不止一个的，需要抓住一个，再解决另一个，否则很容易顾此失彼。

初始化所有人的糖果数为1，

所以先考虑从左往右的单调：只要下一个比当前高，那么糖果数就是当前这个+1，

再考虑从右往左的单调：只要上一个比当前的高，那么糖果数取：max（当前糖果数 + 1，上一个目前的糖果数）。【每次计算的都是必要的糖果个数，所以二者取其大】

图示过程：

编辑

int candy(vector<int>& ratings) {
        int len = ratings.size();
        if (len == 1)
            return 1;
        
        vector<int> a(len, 1);
        for (int i = 1; i < len; i++) {
            if (ratings[i] > ratings[i - 1])
                a[i] = a[i - 1] + 1;
        }
        for (int i = len - 2; i >= 0; i--) {
            if (ratings[i] > ratings[i + 1])
                a[i] = max(a[i + 1] + 1, a[i]);
        }
        int sum = 0;
        for (int i = 0; i < len; i++) {
            sum += a[i];
        }
        return sum;
}

10.860. 柠檬水找零

这个题目和那个加油站有点点像，但是这个题目简单在不用换顺序，就这个顺序往下遍历只需查看是否存在无法找零钱的情况，有就直接return false，否则知道最后也能正确找零钱就return true；

而且钱币面值很小，分情况讨论的情况数少也比较好分析，直接推就可以想到：

给面值计数：

收到5：直接面值5++；

收到10：看有没有5,5--，10++【不符合return false】

收到20：看有没有5和10,5--，10--，20++；否则看有没有3个5，有则面值5-=3，20++；【不符合return false】

bool lemonadeChange(vector<int>& bills) {
        int a_5 = 0, a_10 = 0, a_20 = 0;
        int len = bills.size(), curr = 0;
        for (int i = 0; i < len; i++) {
            curr = bills[i];
            if (curr == 5)
                a_5++;
            else if (curr == 10) {
               if (a_5 > 0) {
                    a_5 --;
                    a_10++;
                }
                else
                    return false;
            }
            else {
                if (a_5 > 0 && a_10 > 0) {
                    a_5--;
                    a_10--;
                    a_20++;
                }
                else if(a_5 >= 3) {
                    a_5 -=3;
                    a_20++;
                }
                else
                    return false;
            }
        }
        return true;
    }

11.406. 根据身高重建队列

这个题目挺有意思，拿到感觉无从下手有点，不知道按0还是按1位置来排序，需要认真分析，我开始想的是无论怎么说都得从小往大排对吧，毕竟你看1号位相同的时候，0号位小的值一般在前面不过也得看具体数字需求，这就是典型的没有处理好两个相互牵制的因素，造成顾此失彼。

仔细想一下1号位的的含义：前面的 >= 本元素值的个数，所以当元素一序按照0号位从大到小排，然后二序按照1号位排；然后依次处理：让当前元素前面只有1号位对应数字的个数个元素。

注意:

因为已经是从小到大排序了，而且要求前面有多少个 >= 自己的，只会多不会少。因此不存在往后插，只会往前移动。

又因为，未处理的时候，前面的元素都 >= 自己，而且按顺序先处理的都是大元素，因此前面的元素都 >= 自己【所以只需要插入从前往后数的第1号位显示的数字的位置上】。

但是不可以用原数组操作，原因在于：你是将当前元素插入对应位置上，但是当前这个元素并没有被你拿走【如果是拿走并插入就没问题】，但是如果没拿走就相当于原来的还在，然后又插了一个，个数变多了，并且将当前元素顶到下一个待取的位置上，索引取值的时候递增，就会重复取这个位置的数。

所以要么重新开一个数组，要么就拿出来再取，

bool cmp(vector<int> a, vector<int> b) {
        if (a[0] == b[0])
            return a[1] < b[1];
        else
            return a[0] > b[0];
    }

class Solution {
public:
    vector<vector<int>> reconstructQueue(vector<vector<int>>& people) {
        vector<vector<int>> result;
        int len = people.size();
        sort(people.begin(), people.end(), cmp);
        for (int i = 0; i < len; i++) {
            result.insert(result.begin()+people[i][1], people[i]);
        }
        return result;
    }
};

12.452. 用最少数量的箭引爆气球

如果题目来思考，可能很难快速读懂题意。

直接看题意：有重叠区域的气球会一次性被引爆。

算最少的箭数，就是算相互不重叠的区域最少有多少个。

看这种题目很容易想到典型的工作（活动）分配、教室分配等；但是需要注意的是，因为时间重叠问题，要求的是相邻之间不重叠【时间不冲突】，但是气球引爆要保证多个气球有一段公共区间，因此要比较最小的结束位置和当前气球区间重叠才能算，如果开始位置脱离了这个最小的结束位置就需要重开一个重叠区域。

当然了说了这么多记得首先要排序：

工作分配的问题是按照：按结束时间进行排序

当前问题：按左按右都行。

int findMinArrowShots(vector<vector<int>>& points) {
        int len = points.size();
        sort(points.begin(), points.end());   //默认先按第一个，再按第二。自己写的排序容易超时，记得用引用用地址排，不用copy备份
        int sum = 1, num = points[0][1];
        for (int i = 1; i < len; i++) {
            if (points[i][0] > num) {
                sum++;
                num = points[i][1];
            }
            else if (points[i][1] < num)
                num = points[i][1];
        }
        return sum;
    }

13.435. 无重叠区间

无重叠区间和前面的题目属于一类题目，就是排序方式和处理重叠区域又有所不同。

按照题意减少删除，尽量保留 —— 就需要做到将覆盖了好多小区间的大区间删掉，从而保留更多的小区间。按照结束位置排序【使早结束的被保留，每次更新记录的就是最小值】，只要和当前记录的区域重叠就会计数并将这个清除掉；只要发现不重叠就更新记录。

bool cmp(vector<int>& a, vector<int>& b) {
    return a[1] < b[1];  //引用传递快于值传递
}

int eraseOverlapIntervals(vector<vector<int>>& intervals) {
        int len = intervals.size();
        int count = 0;
        sort(intervals.begin(), intervals.end(), cmp);
        int num = intervals[0][1];
        for (int i = 1; i < len; i++) {
            if (intervals[i][0] < num) 
                count++;
            else {
                num = intervals[i][1];
            }
        }
        return count;
    }

14.763. 划分字母区间

12,13类题型的变形，需要分析一个字母出现的start，end，然后但凡有勾连的区间都看做一个区间，最后记录区间长度就行。

提前处理字母处理范围，记录为[start,end]这种区间。26个小写字母按顺序，初始化-1。

排序：按开始排序，因为需要求最大长度，所以必须先定开始的索引，必须是最前面的。【如果按照结束来排序有可能开始位置很靠前但是没记录，或者需要随时更新，显得比较复杂】

每次比较开始位置是否和记录的边界是否重合：

如果不重合就说明要重开一个区间，记录当前长度，更新开始索引和结束索引；

如果重合，就要更新结束索引为更大的值 —— max（当前结束值，和之前记录的）【因为只要有一个字母区间重合，就得放在一个区间内，所以以最大的范围为基准】

bool cmp(vector<int>& a, vector<int>& b) {
    return a[0] < b[0];
}

vector<int> partitionLabels(string s) {
        int len = s.size(), index = 0;
        vector<vector<int>> dic(26, vector<int>(2,-1));
        for (int i = 0; i < len; i++) {
            index = s[i]-'a';
            if (dic[index][0] == -1)
                dic[index][0] = dic[index][1] = i;
            else
                dic[index][1] = i;
        }
        sort(dic.begin(), dic.end(), cmp);
        int num = dic[0][1], begin = 0;
        vector<int> result;
        for (int i = 1; i < 26; i++) {
            // cout<<i<<" "<<dic[i][0]<<" "<<dic[i][1]<<endl;
            if (dic[i][0] > num) {
                if (num != -1)
                    result.push_back(num - begin + 1);
                num = dic[i][1];
                begin = dic[i][0];
            }
            else if (dic[i][1] > num){
                num = dic[i][1];
            }
        }
        result.push_back(num - begin + 1);
        return result;
    }

15.56. 合并区间

同样的是12、13、14的变形题目，甚至可以说和14是同一个题目，只是不需要额外处理，是14题的裸题。

按开始索引排序；

判断当前这个范围的开始和记录的结束索引是否重叠

如果重叠，就更新结束索引为更大的一个；

如果不重叠，就以当前的开始和结束索引构建一个新范围加入到结果集，然后更新开始和结束索引。

bool cmp (vector<int>& a, vector<int>& b) {
    return a[0] < b[0];
}

vector<vector<int>> merge(vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end(), cmp);
        int len = intervals.size();
        int begin = intervals[0][0], end =intervals[0][1];
        vector<vector<int>> result;
        vector<int> temp(2,0);
        temp[0] = begin;
        for (int i = 1; i < len; i++) {
            if (intervals[i][0] > end) {
                temp[1] = end;
                result.push_back(temp);
                temp[0] = intervals[i][0];
                end = intervals[i][1];
            }
            else if (intervals[i][1] > end){
                end = intervals[i][1];
            }
        }
        temp[1] = end;
        result.push_back(temp);
        return result;
    }

16.738. 单调递增的数字

这个题目蛮有意思。

开始我分析的是：如果发现当前为比左一位的数大，就可以直接让左一位--，然后后面都变成9。这样忽略了一个问题就是高一位--的时候有可能就又比左2位小了。例如331->329，发现2比3小了，破坏了左边的顺序关系，3应该再--，因此就可以总结出：这个过程是要一直迭代到最左边的，需要从右往左遍历，知道找到最后一个修改的位置，这个位置之后全改成9，前面的顺序从左往右保持递增，才是最终的答案。

于是先将数字拆分成一位一位，然后从低位到高位进行遍历，遇到当前位置的值 > 相邻高位，将高位--，然后记录这个修改的高位的位置；遍历完之后求最终答案：

sum += 高位取位数 pow（10，位数-1），遇到记录的位置之后，后续全变成9 pow（10，位数 - 1）。

return sum；

int monotoneIncreasingDigits(int n) {
        int nn = n;
        vector<int> a;
        while (n > 0) {
            a.push_back(n % 10);   //高位索引大，低位索引小
            n /= 10;
        }
        int len = a.size(), result = -1;
        for (int i = 0; i < len - 1; i++) {
            if (a[i] < a[i + 1]) {
                a[i + 1] -= 1;
                result = i;
            }
        }
        int sum = 0;
        if (result == -1)
            return nn;
        else {
            for (int i = 0; i < len; i++) {
                if (i <= result)
                    sum += (9 * pow(10, i));
                else 
                    sum += (a[i] * pow(10, i));
            }
        }
        return sum;
    }

17.714. 买卖股票的最佳时机含手续费

分析见上。

int maxProfit(vector<int>& prices, int fee) {
        //需要将手续费先支付，每一次算利润都补上，只有断开才是真正支付
        int len = prices.size();
        int minn = prices[0], sum = 0;
        for (int i = 1; i < len; i++) {
            if (prices[i] > minn + fee) {             //能保证赚钱（之前没买的时候保证的是赚够手续费）;之前如果买了，判断实际上是否还是涨
                sum += (prices[i] - minn - fee);
                minn = prices[i] - fee;               //补偿这一次的手续费，下一次扣
            }
            else if (prices[i] <= minn + fee && prices[i] >= minn)//赚不了钱
                continue;
            else
                minn = prices[i];     //最小值更新为新的，刚刚的手续费的确花了

        }
        return sum;
    }
