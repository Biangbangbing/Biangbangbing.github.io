3.二叉树的种类

满二叉树：节点个数不是0就是2。【国际定义】【国内某些教程：子节点个数全是2。】

完全二叉树：节点从上到下，从左到右填充。

平衡二叉树：任意及节点的高度相差不超过1。【AVL，红黑树】【判定方法，中序遍历+单调】

二叉搜索树：左子节点的值 < 根的值 <= 右子结点的值。

平衡二叉搜索树：既是平衡二叉树，又是搜索树。

堆：大顶堆：根节点的值 > 左右节点；小顶堆：根节点的值 < 左右节点的值。

4.二叉树的高度

该节点到叶子结点的最多的路径边的条数。【LeetCode算的是路径上的结点的个数，包括首尾】

代码思路：

后续遍历：当前节点高度 = max（左右子节点高度）+1

先序遍历：更新max；如果左不为空，深度++，回溯深度--；如果右不为空，深度++，回溯深度--；

层序遍历：层数。

5.二叉树的深度

根节点到该节点的最多的路径边的条数。【LeetCode算的是路径上的结点的个数，包括首尾】

树的深度：最底层的叶子结点的深度 = 根节点的高度 = 根节点->最远叶子结点路径上的结点个数。

最大深度：树的深度。

最小深度：根节点->最近叶子结点路径上的结点个数。

最小深度代码思路：

层序遍历：遇到第一个叶子结点退出，层数就是最小深度。

迭代&前序遍历：如果当前是空节点，返回0；获得左子树和右子树的深度，如果当前节点的单个子节点为空的时候，返回另一个子树的高度 + 1，如果拥有两个子节点，返回左右子树的高度的最小值 + 1。

6.二叉树的结点个数

总个数 = 左子树节点个数 + 右子树结点个数 + 1。

代码思路：

递归：前序遍历 + 计数。

迭代：计数。

层序遍历：每层计数。

8.二叉树的构建【强调唯一性】

  1. 利用中序、后序遍历构建。
  2. 利用前序、中序遍历构建。
  3. 利用层序遍历构建。

为什么不可以用前序，后序构建唯一一个二叉树：因为没有中间结点可以切数组分成左右子树。

构建方式：

利用后序（前序）的首个结点来切分中序数组，因为这个结点为当前这棵树的根节点。然后左边右边分别为左右子树节点的值。然后据此分清左右子树的节点个数，以此来分中序数组，然后分别获得了左右子树的后序（前序）、中序数组，然后递归求节点即可，同时赋予节点链接关系。
