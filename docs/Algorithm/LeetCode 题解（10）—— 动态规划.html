1.70.爬楼梯

解题思路：

  1. dp数组含义&下标：dp[i]表示到达第i层的方法数目。
  2. dp递推公式：dp[i] = dp[i - 1] + dp[i - 2];(因为可以走1或2步，因此低1个或者低2个台阶都可以到达当前台阶)
  3. dp数组初始化：dp[1] = 1（走一步）；dp[2] = 2（0-1-2；0-2）【初始化成几都咩有关系，至少2个就可以】
  4. dp遍历顺序：因为从小推出大索引的dp值，因此从小——>大遍历。
  5. dp数组举例：dp[3] = dp[2] + dp[1]（表示抵达第3级台阶可以由第2级跨1步，也可以由第1级台阶跨2步；到达第2级有2种方法，因此到达第三级首先有2种方法，其次到达第1级台阶有1种方法，达到第三级总共有3种方法。）
class Solution {
    public int climbStairs(int n) {
        int a = 1;
        int b = 2;
        if (n == 1)
            return a;
        else if (n == 2)
            return b;
        else {
            int c = 0;
            for (int i = 2; i < n; i++) {
                c = a + b;
                a = b;
                b = c;
            }
            return b;
        }   
    }
}

为了节省空间开销可以不使用数组，使用3个变量来回交换即可，空间开销从O(n)降低为O(1)。

plus：

每次一步可以跨的台阶数目变成不定长度如何变化：感觉有点像11.组合总和问题了。

也是先遍历抵达各个台阶（数字）的数目（组合方法），然后从小到大累计到目标。

因为不同实际迈的步数相同但还是不同的组合，因此112,121,211都是不同的方式。

所以：

外循环遍历台阶数目；从小到大。

内循环遍历各种步数，从小到大，确保步数可以复用。

而且在用到小的时候，小的已经计算完毕不会再计算，因此台阶在外循环，且从小到大。

2. 746. 使用最小花费爬楼梯

解题思路：和上一题基本一样，细节不同

要注意的几个点：

楼顶不在阶梯里面，因此从楼梯跨上楼顶的一步，没有楼顶标注消耗

对于阶梯消耗的理解：可以是从下一步抵达这一层时需要消耗的力气（提前消费）；进入这一层的门票（从这一层出来花费掉）

  1. dp数组&下标：dp[i]：到达第i阶梯的最小花费
  2. dp递归方程：dp[i] = min（dp[i - 1]， dp[i - 2]）+ cost[i]【提前消费，到达i层的消费时包含第i层的消耗，因此最后需要判断dp[n - 2]，dp[n - 1]中的最小值为最终结果（n为阶梯数目，0——(n-1)），达到顶楼没有消耗】
  3. dp数组初始化：dp[0] = cost[0]；dp[1] = cost[1]
  4. dp遍历顺序：从小到大获取值，从小向大遍历。
  5. dp数组举例：dp[2] = min(dp[1],dp[0]) + cost[2]

和上一个题的关联：相当于每走1种路线的耗费是1，最终耗费就是可以走的方案数目。

class Solution {
    public int minCostClimbingStairs(int[] cost) {
        int n = cost.length;
        int[] dp = new int[n];
        dp[0] = cost[0];
        dp[1] = cost[1];
        for (int i = 2; i < n; i++) {
            dp[i] = Math.min(dp[i - 1], dp[i - 2]) + cost[i];
        }
        return Math.min(dp[n - 1], dp[n - 2]);
    }
}

3.62.不同路径

解题思路：

还是求方法数目，1维变成2维

  1. dp数组&下标：dp[i][j]表示到达（i，j）坐标点的路径数目。
  2. dp递归方程：dp[i][j] = dp[i - 1][j] + dp[i][j - 1]（只能向下或者向右，对应只能从上或者左边来）
  3. dp数组初始化：dp[1][i] = dp[i][1] = 1
  4. dp遍历顺序：从左上角往右下角遍历
  5. dp数组举例：dp[1][1] = dp[0][1] + dp[1][0] = 2, dp[1][2] = dp[0][2] + dp[1][1] = 3;

考虑这个题目有3种思路：

  • 因为每次从右，从下走，每次只能有两种选择，最终一定可以抵达右下角，而且一定是最后一步，因此构建2叉树，遇到边界（上下左右墙）剪枝，最终叶子结点的个数就是方法。因为从右（n-1步）或从下走（m-1步），要正好走完这么多步，树深度m+n-2。时间空间复杂度为O(2^(m+n-2))
  • dp数组
  • 因为有（n-1）个右，（m-1）个下，每一次随便选哪个，其实就是一个排列组合问题，总共m + n - 2个操作选右n - 1个，有 C（m + n - 2）(n - 1)种方法。
class Solution {
    public int uniquePaths(int m, int n) {
        int[][] a = new int[m][n];
        for (int i = 0; i < m; i++)
            a[i][0] = 1;
        for (int i = 0; i < n; i++)
            a[0][i] = 1;
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                a[i][j] = a[i - 1][j] + a[i][j - 1];
            }
        }
        return a[m - 1][n - 1];
    }
}

5.343. 整数拆分

解题思路：

  1. dp数组&含义：dp[i]：表示整数组成的的最大值。
  2. dp递归方程：dp[i] = max( max(dp[m]，m） * max(dp[i - m]，i - m)，dp[i])；
  3. dp数组初始化：dp[1] = 1；dp[2] = 1
  4. dp遍历顺序：从小到大遍历，因为大数据依赖分解为小数据，小数据必须是已经已知的。
  5. dp数组举例：dp[3] = max([max(dp[1],1) * max(dp[2]，2)]) = 2 ; dp[4] = 1/3【2】,2/2【4】= 4。
class Solution {
    public int integerBreak(int n) {
        int[] dp= new int[n + 1];
        dp[1] = 1;
        dp[2] = 1;
        for (int i = 3; i <= n; i++) {
            int m = i / 2;
            for (int j = 1; j <= m; j++) {
                dp[i] = Math.max(dp[i], (Math.max(dp[j], j) * Math.max(dp[i - j], (i - j))));
            }
        }
        return dp[n];
    }
}

6.96.不同的二叉搜索树

解题思路：

  1. dp数组&下标：dp[i]：i个节点的BST的种类数。
  2. dp递归函数：dp[i] += dp[j] * dp[i - j - 1]【j范围遍历：0——i-1】
  3. dp初始化：dp[0] = 1，dp[1] = 1
  4. dp数组遍历顺序：从小到大。
  5. dp数组举例：dp[3] = dp[0] dp[2] + dp[1] dp[1] + dp[2] * dp[0]
class Solution {
    public int numTrees(int n) {
        int[] dp = new int[n + 1];
        dp[0] = 1;
        dp[1] = 1;
        for (int i = 2; i <=n; i++) {
            dp[i] = 0;
            for (int j = 0; j < i; j++) {
                dp[i] += dp[j] * dp[i - j - 1];
            }
        }
        return dp[n];
    }
}

7.416. 分割等和子集

解题思路：

这个题目和曾经做过的分硬币，分磁带是一个问题。都是01背包的变形，这个是不可以用贪心的。

  1. 转化背包的思路：设计背包容量为一半的重量，看看最多的时候是不是能装满。
  2. dp数组&下标：dp[i]：代表容量为i的背包最多可以填充的数字。
  3. dp递推公式：dp[i] = max（dp[j]，dp[j - sum[i] ] + sum[i]）
  4. dp初始化：dp[i] = 0
  5. dp数组遍历顺序：外部for先遍历物品，内部遍历dp从大到小遍历【因为当前的值用的都是上一轮的在作比较，如果从小达到会导致小值已经更新过，后面大值再用的时候用的是这一轮的值导致一个物品装了两次】
  6. dp数组举例：[1,5,11,5] dp数组dp[11], dp[1-4] = 1，dp[5-9] = 5，dp[10] = 10，dp[11] = 11，满足分割true。
class Solution {
    public boolean canPartition(int[] nums) {
        int len = nums.length;
        int sum = 0;
        for (int i = 0; i < len; i++) {
            sum += nums[i];
        }
        if (sum % 2 ==1)
            return false;
        sum /= 2;
        int[] dp = new int[sum + 1];
        for (int i = 0; i < len; i++) {
            for (int j = sum; j >= nums[i]; j--) {
                dp[j] = Math.max(dp[j], dp[j - nums[i]] + nums[i]);
            }
        }
        if (dp[sum] == sum)
            return true;
        else
            return false;
    }
}

8.494.目标和

解题思路：

  1. dp思想：找到组合方式：相当于把一些数分为两半 a，b；a赋值为+，b赋值为-；计算得出a+b = sum（当前所有元素的和）；a - b = target；现在只需要找到在所有数字里可以组成a或者组成b的所有组合，他们属于互为补，最后算出都是一样的。因为数组所有数字为正数，因此a一定都是 > ；同时如果数组有负数，a可能是负数，则需要构建dp数组有偏移。

  2. dp数组&下标：dp[i]：表示组成i有几种

  3. dp递归函数：dp[j] = dp[j - nums[i]] (外循环遍历数字，内循环遍历背包重量)

  4. dp初始化：dp[0] = 1

  5. dp遍历顺序：从大向小遍历背包。

  6. dp数组距离： 

    nums = [1,1,1,1,1], target = 3.    5 + 3 = 4; 求出等于4的所有组合数。dp[4] += dp[3]; dp[3] += dp[2]; dp[2] += dp[1]; dp[1] +=dp[0];【0001】【0012】【0133】【1464】【5 10 10 5】  答案为5.
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int len = nums.length;
        int sum = 0;
        for (int i = 0; i < len; i++) {
            sum += nums[i];
        }
        sum += target ;
        if (sum % 2 !=0 || sum < 0)
            return 0;
        else {

            sum /= 2;
            int[] dp = new int[sum + 1];
            dp[0] = 1;
            for (int i = 0; i < len; i++) {
                for (int j = sum; j >= nums[i]; j--) {
                    dp[j] += dp[j - nums[i]];
                }
            }
            return dp[sum];
        }
    }
}

        int len = strs.size();

                else

            }

            dp[i] = new int[n + 1];

                dp[i][j] = 0;
            }

            for (int j = m; j >= strmap[i][0]; j--) {

                    dp[j][k] = max(dp[j][k], dp[j - strmap[i][0]][k - strmap[i][1]] + 1);

            }
        }

12.322. 零钱兑换

解题思路：

硬币无限：完全背包。

要求：组成目标点额硬币个数最少，求硬币数目。

  1. dp思想：在每一个钱币值下，求出所有硬币 的 剩余钱的最小硬币数 + 1。
  2. dp数组&下标：dp[i]：代表组合面值为i的最少硬币数。因为是计数硬币个数，因此多加一个硬币要增1。
  3. dp递归函数：dp[j] = min{dp[j - coins[i]]} + 1
  4. dp遍历顺序：从小到大遍历（外层遍历背包容量【目标值】，内层遍历钱面值集合，可以重复遍历）【外部循环只能遍历一次，且不可反复；内部循环可以反复多次——代表面值可以使用多次】【如果外部遍历面值，内部遍历容量，在一种面值的情况下，将所有可能放的下的容量都尝试一次，因为从小到大计算，因此也相当于可以使用多次面值】
  5. dp初始化：因为是硬币数目，因此dp[0] = 0。
  6. dp数组举例：
coins = [1, 2, 5], amount = 11

dp[0] = 0, 其他默认都是最大值 INT_MAX。

dp[1] = min(dp[1 - coin[0]] + dp[1 - coin[1]] + dp[1 - coin[2]]) + 1 = 1,【面值为1的组合种类】

dp[2] = min(dp[2 - coin[0]] + dp[2 - coin[1]] + dp[2 - coin[2]]) = min(1,0)+1 = 1

dp[3] = min(dp[3 - coin[0]] + dp[3 - coin[1]] + dp[3 - coin[2]]) =min(1,1) + 1 = 2

31.115.不同的子序列

题意：求在字符串s子序列中字符串t出现的次数。【注意子序列定义：不需要字符串每一位连续，只需要相对位置一致即可】

求的是出现的次数，有些字符是可以重用的，只要有一位的组成字符不同就是一种不同的方法，相当于s的字符串的每一个字符都有一个编号。组合的编号不一样，则都是一种新的组成方式。

  1. dp数组&下标：dp[i][j]：代表以第i个字符结尾的s，以j个字符结尾的t，s的子序列中t出现的次数。
  2. dp递归函数： s[i] == t[j]，dp[i][j] = dp[i - 1][j - 1]（之前有的次数） + dp[i - 1][j]，（不用当前字符，但是也能组成t[j]的字符次数） s[i] != t[j]，dp[i][j] = dp[i - 1][j]（不用s的当前字符匹配） 由此看到，因此需要从将s放到外层循环遍历，将t放到内存循环遍历。
  3. dp遍历顺序：从前往后遍历。将s放到外层循环遍历，将t放到内存循环遍历。
  4. dp初始化：dp[0][0] ,如果第一个字符相等 = 1，否则 = 0；之后如果相等 = dp[0][i - 1] + 1,不相等 = dp[0][i - 1]
  5. dp数组举例：
 int numDistinct(string s, string t) {
        int len1 = s.size();
        int len2 = t.size();
        if (len1 < len2)
            return 0;
        uint64_t **dp = new uint64_t*[len1];
        for (int i = 0; i < len1; i++) {
            dp[i] = new uint64_t[len2];
            for (int j = 0; j < len2; j++) {
                dp[i][j] = 0;
            }
        }
        for (int i = 0; i < len1; i++) {
            if (i == 0 && s[i] == t[0])
                dp[i][0] = 1;
            else if (s[i] == t[0])
                dp[i][0] = dp[i - 1][0] + 1;  
            else if (i > 0)
                dp[i][0] = dp[i - 1][0];
        }
        for (int i = 1; i < len1; i++) {
            for (int j = 1; j < len2; j++) {
                if (s[i] == t[j]) {
                    // cout<< dp[i - 1][j - 1]<<"   "<<dp[i - 1][j]<<"   "<<dp[i - 1][j - 1] + dp[i - 1][j]<<endl;
                    dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j];
                }
                else
                    dp[i][j] = dp[i - 1][j];  
            }
        }
        return dp[len1 - 1][len2 - 1];
    }
